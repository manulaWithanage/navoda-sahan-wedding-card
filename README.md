# Navoda & Sahan - Online Wedding Invitation Card

A digital wedding invitation website for **Navoda & Sahan**.

## Features & Tech Stack
- **HTML5 & Vanilla CSS3**: Elegant design, visual hierarchy, and responsive mobile-first layout.
- **Vanilla JavaScript**: Interactivity, countdown timer, smooth scroll reveal, and canvas animations.
- **Google Sheets RSVP Integration**: Interactive guest RSVP capture.

## Directory Structure
```text
Navoda-wedding-card/
├── index.html        # Main webpage layout
├── index.css         # Styling system & animations
├── app.js            # Interactive logic & countdown
├── README.md         # Setup guide
└── assets/           # Images & graphic assets
```
